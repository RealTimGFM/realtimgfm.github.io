Nextcloud with Docker Compose.

I used Docker Compose to host Nextcloud with separate application, database, and cron containers. Compose keeps the related service definitions together, making their dependencies and administration easier to understand.

Persistence
Volumes or host bind mounts keep data outside a disposable container layer. Recreating a container can retain mounted data; deleting that storage can still lose it.
Administration & restart
SSH is the documented administration route. Compose supports service inspection, logs, and explicit restarts.

Background-job role: Nextcloud administration documentation.

Private Access & Network Security.

Tailscale provides private connectivity between authorized devices in a tailnet. I configured Tailscale Serve to offer HTTPS access to Nextcloud and forward requests to a local loopback service on port 8080. This avoids adding a public Nextcloud endpoint just to reach files remotely.

Reducing public exposure narrows the reachable service surface, but it does not secure the whole server. Tailnet authorization, Nextcloud and SSH authentication, system updates, service configuration, and device security remain necessary. Private networking also makes access dependent on authorized, connected devices.
