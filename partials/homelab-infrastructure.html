Technical notes
  • Separate containers keep the application, PostgreSQL, Redis and scheduled jobs independently manageable.
  • Volumes or bind mounts preserve data beyond a container's lifecycle. Deleting that storage can still lose data; the database retains its own persistent records.
  • Cron uses shared application configuration and data so jobs can run without web traffic.
  • Compose groups service definitions and dependencies for inspection, logs and explicit restarts over SSH.
  • Tailscale Serve forwards HTTPS to the local loopback service on port 8080. Redis caching and locking settings, mount paths and backup procedures are not established by the capture.
