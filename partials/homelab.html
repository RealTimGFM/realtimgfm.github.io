04 / Dedicated network services

Small machine. Clear responsibility.

The Raspberry Pi 4 runs Pi-hole for local DNS and domain filtering. I use SSH to administer it and trace DNS behavior when troubleshooting the network.

Keeping this lightweight infrastructure on its own device separates DNS and filtering from the heavier workloads on the Debian server.

06 / Engineering practice

What I learned.

Think in services
Manage persistent Linux services and their processes remotely through SSH, beyond a desktop session.
Trace connectivity problems
Distinguish DNS issues from network and service failures across real hardware and software.
Work within resource limits
Use CPU and memory monitoring to understand the constraints of a running server workload.
Separate responsibilities
Keep DNS and filtering on the Pi while the Debian server handles heavier workloads.
