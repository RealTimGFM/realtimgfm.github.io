01 / Server workloads

Debian home server

A Debian 12 home server gives me a practical environment for Linux administration: configuring the network, administering the machine over SSH, and managing services and processes that host server workloads.

Minecraft is a real-world workload for these experiments. Hosting the server lets me explore how resource use and network configuration affect a running service.

  • Administer the server remotely through SSH.
  • Monitor CPU and memory usage while workloads run.
  • Troubleshoot service, process, and connectivity issues.

02 / Network services

Raspberry Pi & local DNS

The Raspberry Pi serves as a lightweight, dedicated Linux device for network services. Pi-hole handles local DNS and domain filtering, with its dashboard providing a view into DNS queries on the home network.

I use SSH for remote administration and explore network troubleshooting through DNS behavior. Keeping these services on the Pi separates lightweight network infrastructure from the heavier workloads on the Debian server.

04 / Engineering practice

What I learned

Think in services
Configure Linux machines to run persistent services, and manage their processes remotely through SSH rather than relying on a desktop session.
Trace connectivity problems
Distinguish DNS issues from network and service failures when troubleshooting across real hardware and software.
Work within resource limits
Use CPU and memory monitoring to understand the constraints of hosting workloads on a home server.
Separate responsibilities
Keep lightweight DNS and filtering services on the Raspberry Pi while the Debian server handles heavier application and game-server workloads.
